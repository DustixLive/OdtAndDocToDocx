# ODT / DOC → DOCX Converter

Простой конвертер файлов **.odt** и **.doc** в **.docx**.

- Не требует Microsoft Office, LibreOffice или OpenOffice
- Поддерживает обычный текст и **жирный** шрифт (в ODT)
- После успешной конвертации оригинальный файл удаляется
- Работает рекурсивно по всем подпапкам

> Подходит для документов, в которых используется только простой текст и выделение жирным.

## Возможности

| Формат | Текст | Жирный | Примечание |
|--------|-------|--------|----------|
| `.odt` | ✅ | ✅ | Хорошее качество |
| `.doc` | ✅ | ❌ | Только текст (бинарный формат сложный) |

## Установка

```bash
pip install -r requirements.txt
```

Или по отдельности:

```bash
pip install python-docx odfpy olefile
```

## Использование

1. Положи `converter.py` в папку с документами (или в корень нужной директории).
2. Запусти:

```bash
python converter.py
```

Скрипт:
- Найдёт все `.odt` и `.doc` во всех подпапках
- Создаст рядом `.docx`
- Удалит оригиналы после успешной конвертации
- Пропустит файлы, если `.docx` уже существует

## Сборка в .exe (Windows)

Если нужен один исполняемый файл без установленного Python:

```bash
pip install pyinstaller
pyinstaller --onefile --console --name OdtDocConverter converter.py
```

Готовый файл появится в папке `dist/OdtDocConverter.exe`.

## Требования

- Python 3.8+
- Библиотеки из `requirements.txt`
